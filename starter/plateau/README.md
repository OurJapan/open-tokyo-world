# 公式1タイルからBlenderへ取り込む

港区2025の24地物と既存の広場6部品を、旧都市blend・保存キャッシュなしで組み立てる限定的な試験です。配布サービス・全都市取込・実物精度の改善ではありません。確認したdata221だけに対応します。

リポジトリ全体とPython 3.12、Blender **4.5.1 LTS**が必要です。Pythonへの追加pipインストールは不要。復号・座標計算はBlender同梱のDraco・NumPyを使います。まずWindowsで検証し、他OSは未検証です。インターネットから公式の2ファイル、合計1,658,929 bytesを取得します。

```powershell
python starter/plateau/run.py --blender "C:/Program Files/Blender Foundation/Blender 4.5/blender.exe" --output build/plateau-first
```

出力先は毎回新しいフォルダーにしてください。既存フォルダーへの上書きは拒否します。URL・サイズ・SHA-256をコードに固定し、不一致・配信終了・未対応形式なら失敗します。別年度への自動置換、個人キャッシュへのフォールバックはありません。通信や実行に失敗するとrun.jsonにok=falseを記録し、原因をログに残します。

成功するとreview.htmlで全景と入口付近を確認できます。scene.blendには24個のgml_id付き建物と6個の広場部品、画像1枚を保存します。georeference.jsonには元ENUの範囲、建物ごとの高さ移動、画像・メッシュ・UVのハッシュを残します。別Blenderプロセスで開き直して検証・CPUレンダーし、validation.jsonとrun.jsonを出力します。旧都市ファイルのパスは指定しません。

高さは旧表示の互換モードです。地理座標からENUへ変換後、建物ごとに最小zを0.32mへ合わせます。実際の地形・標高として利用しないでください。公式の森JP形状も保持するため、従来の修正済み森JPモデルと同時に読み込むと重複します。将来の置換ではgml_idで識別します。

これは新規取込の確認画像で、変更前後の比較ではありません。広場との接触や遮蔽は人間による画像レビューが必要です。現実の段差、道路や地形、形状の完全な位相検査、他OS、初参加者テストは未確認です。[出典と加工](NOTICE.md)を確認してください。出力を勝手にReleaseへアップロードする処理はありません。

通常の確認は `python -m unittest discover -s tests`。ダウンロード、GLBの外部依存拒否、デコーダー、保存後の画像・材質・ID検査は異なる確認なので、軽量CI成功だけで実機取込成功とは扱いません。
