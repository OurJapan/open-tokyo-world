# 東京タワーの塔脚周辺の歩道・側溝の接続修正

PR #63の保存候補を固定入力に、三つの局所範囲で道路・歩道面の継ぎ目を修正します。四つの基礎を確認し、大きな乱れがある塔の制作座標X正側の二箇所と、北側の対向する基礎前に残った側溝片を編集します。塔体・基礎・FootTown・前回の南側斜面は保持します。

## 原因と修正方法

旧 `work/tokyo60/build_city.py` は、OSMの各線分を個別の長方形として生成していました。後段でそれらの上面を合成して側溝を作るため、曲がり角・細かく分割された階段経路にV字の切れ目や細い舗装片が残っていました。旧 `steps` の既定幅は4mで、車道と同じasphalt分類になっていました。

保存OSMは `f04e8e70ab24a61ca749375d1ef37401feb0fdc840cc506b670ef71454a6a8ab` へ固定しています。南側のway 1344798538はタクシー乗り場の車路、30525080は駐車場通路、30526238は周囲の車道です。北側の1245345677は8段の階段、1245345676・1245345678はその前後の歩道です。実在する経路として保持し、断片と見なして一括削除しません。

同じ線形・道路幅から角を丸めた連続輪郭を作り、車道・側溝・歩道を重なりのない面へ再分割します。車道のタグ幅または旧モデルの既定幅、車道脇の舗装幅1.05m、側溝幅0.24mを使用します。地図で明示された歩行経路は歩道として扱い、階段経路には仮の幅2mを採用します。これらは現地測量値の確定を意味しません。

編集矩形は塔の制作座標で `(33.5,-63)–(67,-30)` と `(33.5,20)–(63,60.5)` と `(-51,45)–(-38,61)`、高さ0.61m以下です。変更対象は `asphalt 15s road detail`、`gutter 15s road detail`、`pavement_0 unified road` の3メッシュです。各対象の元頂点は動かさず、矩形を横切る面だけ分割し、範囲外の面・材質番号・smooth・表示・選択状態を保持します。輪郭計算は1mm格子へ固定し、丸めで生じる素材間の微小な重なりも除きます。UVや未対応属性がある入力は停止します。

新しい歩道は高さ0.30–0.46mの閉じた厚みを持ち、塔の台座・既存斜面の投影を除外します。車道・側溝は既存と同じ0.30mです。実際の階段の蹴上げ・地形は復元せず、現段階では地図上の歩行経路を平坦なモデルへ接続する修正です。8段を推定高さで造形したとは扱いません。

## 検証・再実行

- 入力blend・対象メッシュ・生成planのSHA-256を固定。
- 保存後に別Blenderプロセスで開き直し、対象外オブジェクト・材質・画像・表示設定・変換・個数を照合。
- 元頂点・範囲外の面と属性の一致、残った旧断片の面積、範囲外表面積の保存を検査。
- 保存した新しい歩道の閉鎖性・面向き・正体積とplanの座標・面構成を照合。
- タクシー車路・周囲の車道の代表点と、北側の歩行経路・基礎の空きを検査。保存された歩道上面三角形の重心へZ=1.95mからrayを落とし、歩道上面へ届くことも確認。点検査であり、連続した全衝突の保証ではありません。
- 同じカメラ・照明・描画設定で、四つの基礎と敷地全景を含む8視点のBefore/Afterを作成。

```powershell
# Shapely 2.1.2 / GEOS 3.13.1 の制作環境でplanを準備
python scripts/prepare_tower_footway_v5.py --osm SAVED_OSM --output NEW_PLAN
# 公開planのhashを入力JSONに固定した版で、各PHASEを別プロセスで実行
& BLENDER --factory-startup --background --threads 2 --disable-autoexec --python-exit-code 1 --python scripts/tower_footway_v5.py -- --phase PHASE --input PR63_AFTER --output NEW_RUN
python -m unittest discover -s tests
python -m compileall -q scripts tests
```

## 制約と公開範囲

道路と塔脚の厳密な地理登録、現地の歩道幅・階段高、歩行適合性は未確定です。既存の塔脚と道路の配置矛盾を、車道中心線をずらして解決したとは扱いません。編集範囲外の道路形状と南側の対向する基礎周辺は保持します。基礎台座の実寸法や塔全体の鉛直基準も今回の対象外です。
