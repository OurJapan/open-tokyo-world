# 写真を撮るだけで素材を残す

撮影後の分類・メモ・対象選択・寸法入力は不要。撮影直後にJPEGと取得できた位置・方位をIndexedDBへ保存し、カメラを開いたまま次を撮影できる。保存失敗時だけ写真を開き、ZIPで救済する。

## 自動送信

「撮影した写真を自動で送る」で参加コードと保存への同意を設定する。このページの撮影セッション内で、その後撮った写真を順に送信する。通信がない場合は端末保存し、オンライン復帰で再試行。失敗時は自動再試行を繰り返さず、写真を残す。明示的な再試行も可能。

送信前に同意情報を含む内容を固定・端末保存し、受付結果が不明でも同じID・同じ内容で再送する。コードはメモリのみで、写真・ZIP・IndexedDBには含めない。再読込後はコードと同意を再設定する。再設定によって再送されるのは過去に自動送信へ同意した送信待ち写真のみ。端末保存だけで撮った写真は勝手に送らない。

自動送信中は一覧からの編集・削除を止めて保存競合を防ぐ。停止操作後も実行中の1件は完了する可能性がある。ブラウザを閉じた後のバックグラウンド送信は保証しない。利用枠はAPIの既存制限が適用される。

## 場所と寸法の証拠

飯田橋周辺の固定OSM建物カタログと、撮影時のGPS・方位から最大8件の建物候補を自動添付する。GPS欠落・誤差50m超・データ範囲外では候補を作らず写真だけ保存する。撮影座標は外部の地図APIへ送らない。カタログはオフライン用にキャッシュされる。

候補の距離と方位は順位付けの参考で、画像の内容や遮蔽物を認識していない。`image_analysis_performed:false`、`status:candidates_unverified` を保存する。地図の外形から求めた東西・南北の幅と存在する高さタグは `map_reference_dimensions` に出典付きで格納する。写真の対象物の実寸ではなく、欠落した高さを補完しない。`feature_id` と `camera_pose` は未確定のまま。

撮影時点では画像解析を行わない。保存したZIPを[PC側の推定CLI](../tools/photo_estimation/README.md)に渡すと、写真の対応点を照合し、GPS条件を満たす場合に点間距離を暫定推定できる。建物全体の実寸や地物の特定は未実装。寸法は `dimension_status:unresolved` とし、自動生成した数値を実測と表示しない。3Dモデル生成も起動しない。

## 出典と検証

OSM取得日時・クエリ・元データSHAはカタログ内に記録。© OpenStreetMap contributors、ODbL-1.0。再生成は `node scripts/build-target-catalog.mjs <raw-json>`。配布データの利用条件は `public/data/BUILDINGS-NOTICE.md` を参照。

`pnpm test` で候補の位置・方位・欠測と送信キューの同意・並行撮影・停止・再送を検証する。API URLを設定してbuildし、4181番でpreviewを起動後、`BROWSER_CHANNEL=msedge pnpm test:browser` で模擬カメラ・模擬GPS・模擬APIを使う。実写真はテストで送信しない。実機Safariと現地での対象特定精度は別途確認が必要。
