# 東京タワーの駐車区画・地盤・塔脚外装

PR #65 の保存候補を入力に、台座や南側舗装に重なる駐車区画、北側の階段経路、南側入口へつながる舗装、台座外装と下部鉄骨を修正します。実写と地図・標高資料を照合した再現案であり、測量・施工図に基づく完成モデルではありません。

## 修正内容

- 駐車白線は旧生成コードの「3本で1区画」という単位で調べ、台座の上部投影＋0.5mまたは南側舗装と重なる8区画を削除します。残る7区画の頂点・面は完全保持し、根拠のない移設区画は追加しません。
- 台座は高さ2mの箱から、上部に向かって広がる石調外装へ変更します。平面上部の約6.8m角はv6の保存OSM外形を維持します。写真で確認した傾斜とパネル割りを形状へ反映し、高さ7mはOSM記載値を暫定採用します。下部寸法比0.72、パネル寸法・色は写真からの推定です。地下基礎の形状を示すものではありません。
- 既存鉄骨と16枚のベースプレートを台座上端に合わせて持ち上げ、高さ30mまで滑らかに元の高さへ戻します。水平位置・接続・30m以上の頂点を保持します。施工報告の接合部写真・補強図を参考に、下部節点へプレートとボルトを追加します。配置・寸法・本数は模型上の推定で、実構造のボルト配置を確定したものではありません。
- 北側OSM階段経路の8段を立体化し、歩道・車道・側溝・地面を局所的に接続します。DEMの端点標高差2.2mを8段に配分した蹴上げ0.275mは暫定値です。1m DEMから個々の段差は測れないため、実際の段差や踊り場は追加の現地資料が必要です。長い踏面と手すりを設けていますが、通行・アクセシビリティ基準への適合を意味しません。
- 南側舗装は既存入口の高さ4.4mを保持し、南側駐車場の標高差に合わせた高さ3.2mから入口へ連続させます。外周は旧地盤との接続を保持します。

## 標高と資料の扱い

国土地理院の標高取得APIは全22点で「1m（レーザ）」を返しました。正面18.6m、階段両端16.7m／18.9m、南側入口22.7m、南側駐車場21.5mです。これは地形DEMであり、建物の敷居・段鼻の実測値ではありません。旧都市の絶対標高基準は未確定のため、正面歩道Z=0.46mと南側入口Z=4.4mをそれぞれ局所基準として扱っています。敷地全体の標高整合が完了したとは報告しません。

地形の編集は塔ローカル座標の北側矩形内に限定し、周囲の旧平坦地盤へ滑らかに戻します。地面の元の外側面・底面・隅8頂点は保持します。地図・DEM・写真の時点は異なり、実物との精密な登録は未検証です。

地盤が粗い舗装面を突き抜けないよう、道路・歩道の三角形の平面辺長を0.6m以下へ分割しています。階段脇は手すり外縁まで切り欠き、元の曲線経路と段の外形の差による細い舗装片を除去しています。

[資料台帳と採否](../areas/tokyo-tower/tower-ground-v7-sources.json) / [派生計画](../areas/tokyo-tower/tower-ground-v7-plan.json) / [固定入力と駐車区画監査](../areas/tokyo-tower/tower-ground-v7-input.json)。v6で不採用としたOSM高さ7mは、今回の写真による背の高い外装の確認を受けた暫定採用です。地下図の88mを地上台座間隔に読み替えることはしません。

## 検証と比較

保存した候補を別Blenderプロセスで再度開き、原本保護、変更範囲、元の材質、閉じた立体、法線、プレート支持、残存白線、道路編集範囲外、階段・歩道の表面遮蔽を検査します。9オブジェクトを変更し、手すり・階段・外装目地・接合部の4オブジェクトを追加します。

歩道の検査は新たに生じた遮蔽を対象にします。元からある点字ブロックや車止め等は、変更前後の同じ地点で対象物と高さが一致し、舗装高さも変わっていない場合だけ既存設備として別記します。既存設備を含めて歩道全域が障害物のない状態になったという意味ではありません。

[同条件10視点の変更前後](../renders/previews/tower-ground-v7/README.md) / [保存後検証](tower-ground-v7-validation.json)。画像には北側階段と下部接合部の専用視点を含みます。人間による画像の採用判断は未完了です。

実行は `scripts/tower_ground_v7.py --phase build / validate / render-before / render-after` を用います。固定したv6候補を `--input`、新しい非公開ディレクトリを `--output` に指定します。計画の再生成はShapely 2.1.2と `scripts/prepare_tower_ground_v7.py --osm 保存OSM --output 新規JSON` を使用します。
