# 参加体験とコミュニティ連携

状態：設計案。参加サイト、通知、貢献マップ、外部連携は未実装。団体との提携は未締結。

## 参加体験

「街を知っていることが貢献になり、自分の情報で街が変わる」を軸にする。
将来の参加サイトでは地図から場所を選び、写真や一言で報告できるようにする。裏側でIssueに整理し、AIによる調査・修正、Before／After、人間の承認、反映通知をつなぐ。

初期はGitHubの報告フォームで受け付ける。GitHub不要の入口は今後実装する。

## 貢献へのリターン

- 反映通知とBefore／After。
- 本人が希望する場合の更新履歴へのクレジット。
- 改善や確認に参加した場所を記録する貢献マップ。

投稿数の競争より、資料の有用性や丁寧な確認を評価する。人気投票は改善の優先順位の参考とし、現実に正しいことの証明には使わない。金銭報酬は現時点では約束しない。

## 外部との協力

PLATEAU、OpenStreetMap、OSGeo、Blender、地域シビックテックを連携候補とする。外部成果の取得元・版・地物IDと本プロジェクト独自の変更を分けて保存する。外部更新は影響とBefore／Afterを確認し、人間の承認後に反映する。

こちらからは再利用できるツール、不整合の報告、検証結果を返す。外部への提案・データ編集は相手のルールと担当者の確認を経て行う。参加団体のクレジットも希望を確認して記録する。

最初は東京タワー周辺で一件の報告から反映まで通し、元作者以外の参加者とそのAIでも作業できるかを確認する。
