# 東京タワーの敷地方向・南側地盤・屋上・階段接続

PR #60と南側手すり修正PR #61の保存モデルに対する増分です。正面が真北を向く近似配置と、南2階入口へ仮の直階段で入る構成を見直し、屋上の周辺建屋・設備と展望室へ続く床を補います。

## 変更と根拠

- **方位**：OSMにある四つの塔脚ポリゴンの重心を照合した軸角度は約−33.67度です。塔・両展望台・追加内装・窓枠・床金物・FootTownの110部品を、既存原点の周りに−33.7度一体回転します。元から位置変換を持つ床金物24個も、その変換に回転を合成します。道路・街路樹・他の建物は移動しません。これは地図に基づく方位修正であり、測量による地理登録ではありません。
- **南側地盤**：国土地理院の1mレーザDEMでは、正面側の照合点が18.7m、南入口側が22.7m、南側の駐車場内が21.6mでした。公式案内の「2階出口が駐車場へ直接接続」と整合します。仮階段25段と外側の手すり・支持部を除き、既存2階敷居Z=4.4へつながる舗装面に変更します。外縁は旧市街の平坦面へ補間しており、完全な現地地形の復元ではありません。西側駐車場は未変更です。
- **屋上**：公式RF案内と2023年の撮影者本人の写真を参照し、外周寄りの低い建屋3棟、ルーバーを持つ設備2列、角ダクト、中央棟脇の配管を追加します。屋上階段入口と中央昇降路の空きを保ちます。建屋の寸法・高さ・機器の正確な配置は推定です。
- **階段接続**：既存の最終踊り場Z=145.1から、中央設備区画を通って既存の客用床まで床と手すりを追加します。中央壁の限定範囲に開口を設け、その範囲を塞いでいた仕上げ・金属扉・下地・見切りも切り欠きます。実測した内装平面の再現ではなく、既存モデルの途切れた経路をつなぐ修正です。

[出典・採用値・未確認事項](../areas/tokyo-tower/tower-site-v3-sources.json)に、URL、地図のway版、照合点、参照原本のhashを記録しています。地図から導出した重心座標は © OpenStreetMap contributors、ODbL 1.0です。国土地理院の標高は相対高低の照合に用い、旧モデルに実標高の基準を割り当てません。参考写真・PDF・地図の原本、都市blendや旧テクスチャは公開しません。

## 上部架構の確認結果

上部支持材の外側端点16点と保存モデルの塔体を照合しました。端点から鉄骨表面までの距離は最大約0.018mで、現行部材の幅内で接続しています。この箇所に架空の「接合部の隙間修正」は加えません。

メーカー・施工者資料は、カゴ・7本の吊り索・救出階2箇所などを裏付けますが、シャフト専用架構の全寸法・柱数・横梁間隔は確定できませんでした。24区間の架構、救出階の制作高さ、未確認の索帰路・機械室内部、昇降動作は引き続き未検証です。今回、上部架構には塔全体と同じ方位修正だけを適用します。

塔脚・FootTownの外形寸法、地理原点と周辺地物の厳密な一致も未確定です。文化庁資料の「脚間80m」から、測定対象が確定しないまま既存の脚中心・台座外形を一律縮小する変更はしていません。

## 再実行と検証

[固定入力と対象110部品](../areas/tokyo-tower/tower-site-v3-input.json)を使用します。この入力は、PR #60候補に取り込み済みPR #61の手すり増分を再実行し、別プロセスで保存後検査したものです。一般のcity登録を変更しません。入力は保存せず、各実行で新しい出力先を使用します。

```powershell
# PHASEを build → validate → render-before → render-after の順で別々に実行
& BLENDER --factory-startup --background --threads 2 --disable-autoexec --python-exit-code 1 --python scripts/tower_site_v3.py -- --phase PHASE --input PINNED_INPUT --output data/local/reviews/tower-site-v3-final
python -m unittest discover -s tests
python -m compileall -q scripts tests
```

保存後の検証は生成処理を呼ばず、対象外部品・素材・画像・metadata、回転行列、保持メッシュ、切り欠き範囲外の部材、入口への地盤接続、階段から客用床までの床と頭上空間を検査します。非表示部品は保存された変換値と、一時的に表示して評価した行列を照合し、表示状態を戻します。検証プロセスはモデルを保存しません。既存の空メッシュ・modifier指紋の制約は残ります。塔のBEVEL設定は追加で変更前後照合します。

南側舗装は外縁を狭め、既存道路の表面に合わせた端部高さ0.48mから補間します。周囲の都市を含む298地点で、既存建物が舗装を覆わないことを確認します。これは間隔3mのサンプル検査であり、敷地全体の衝突や境界一致を保証するものではありません。

比較は同一カメラ・照明・seed、Blender 4.5.1 LTS、Cycles/OptiXで行います。既存8視点に敷地俯瞰・南入口・屋上設備・展望室接続・上部架構の5視点を加えます。技術検査と人間による実物精度・採用の判断は区別します。
