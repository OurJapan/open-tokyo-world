# 東京タワー地上台座と道路の位置合わせ

PR #64 の保存候補を入力に、地上台座4基と下部鉄骨・接合プレートを保存OSMの台座外形へ合わせます。台座変更に伴う旧輪郭の切り欠きは、前回と同じ3範囲内で道路・側溝・歩道を再生成して埋め直します。道路中心線と幅の決め方は前回と同じです。保存時の丸め誤差で旧境界の側面を残さないよう、3つの編集矩形を各辺1mmだけ拡張しています。

これは地図に基づく暫定補正です。現地測量、実構造の復元、塔全体の地理登録完了を意味しません。

## 根拠と修正判断

- 旧モデルの台座は10.5m角、中心は塔ローカル座標の `(±44, ±44)` でした。v4で採った88mは歴史資料の地下基礎・繋ぎ梁の図12に由来します。地上台座中心間隔へ直接読み替える根拠が足りないため、今回の配置基準としては使用しません。v4は履歴として保持します。
- 保存OSMの台座 way `1244967004`〜`1244967007` はいずれもversion 2、更新日2024-02-01です。各外形を囲む最小回転長方形を用い、約6.8m角の平面形と地図座標を採用します。台座ごとのずれを実物の構造的な非対称性の証拠とは扱いません。
- 文化財資料の「脚間80m」だけでも測定端点を確定できません。公称80mや地下図88mへの一律拡縮、OSMにある高さ7mの採用は行っていません。

[出典・採否](../areas/tokyo-tower/tower-registration-v6-sources.json)と[派生形状・経路](../areas/tokyo-tower/tower-registration-v6-plan.json)に入力hash、外形、座標変換、推定の範囲を記録しています。座標系は旧都市の東X・北Yと原点を継承し、塔の−33.7度回転を逆変換したローカル座標で処理します。

## 変更範囲

変更は台座、橙色鉄骨、接合プレート・ボルト、道路3メッシュの計6オブジェクトです。台座の高さ0〜2mは継承した推定値です。鉄骨と接合部は台座の縮小・移動に追従し、高さ30mまでに元の位置へ滑らかに戻します。30m以上の全頂点と、FootTown・南側舗装・上部タワーの他のオブジェクトは保持します。この補間形状・部材断面は施工寸法を再現したものではありません。

鉄骨の接続を切らないため、変形範囲でメッシュの辺が脚の象限をまたがないことも検査します。プレート16枚・ボルト64本を保持し、各プレートの全隅が台座に支持され、鉄骨に接することを保存後に確認します。

保存後に別Blenderプロセスで開き、原本hash、変更許可範囲、材質・変換・オブジェクト数、閉じた立体、法線方向、台座外形、支持関係、歩道表面の遮蔽、道路編集範囲外の保持を検査します。

[同条件8視点の変更前後](../renders/previews/tower-registration-v6/README.md) / [保存後検証](tower-registration-v6-validation.json)。画像は同じカメラ・照明・OptiX・1280×848・32 samples・seed 0です。人間による画像の採用判断は未完了です。

実行は `scripts/tower_registration_v6.py` の `--phase build / validate / render-before / render-after` を用います。入力は固定したv5候補、出力は新しい `data/local/reviews/` 配下を指定します。計画の再生成にはShapely 2.1.2と `scripts/prepare_tower_registration_v6.py` を用い、保存OSM2件を渡します。旧v5のデフォルト計画は変更前と一致することを別途確認しています。

## 残る精度の制約

地図外形と道路は異なる保存時点のOSMです。衛星測位・現地測量で絶対位置を検証したものではありません。塔の原点、標高基準、実地形、台座の立体形状、8段階段、現実の鋼材寸法と非対称性は未解決です。道路幅と高さにも旧モデルの推定を含みます。台座との平面重なりを除くためのマスク処理は、現実に十分な通行幅があるという証明にはなりません。
