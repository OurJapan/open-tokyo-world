# 東京タワーの基礎中心間隔と南側舗装の接続

PR #62の保存候補を固定入力とし、四つの基礎中心、連動する下部鉄骨・接合部、南入口の舗装を修正します。全4メッシュへの増分で、部品や素材は追加しません。

## 寸法の根拠と修正

旧モデルの台座中心はX・Yとも±47.5mで、中心間隔は95mでした。日本地震工学会掲載の「東京タワーの建設と振動性状」復元資料の基礎平面図（PDF 115ページ、本文106ページ、Fig.12）では、内側の80m寸法とは別に、基礎中心線を通る88mの寸法線を確認できます。日鉄エンジニアリングの資料も、東京タワーの足元を一辺約88mの四角形と説明しています。

この88mを基礎中心間隔に採用し、四つの台座中心を±44mへ移動します。台座の10.5×10.5×2m外形は旧モデルの推定値を保持します。図のピクセルから細かな現況寸法を読み取ったとは扱いません。

下部鉄骨と16枚のベースプレート・64本のボルトにも連続的な水平補正を適用し、Z=2mでの脚中心を台座中心へ合わせます。補正量はZ=52mでゼロになる滑らかな補間です。頂点の高さ、元の面接続、材質割当、表示状態、BEVEL設定を保持します。Z=52m以上の頂点座標と、それ以外の展望台・昇降路・建物は変更しません。下部鉄骨の曲線や部材寸法は、実測図面から再設計したものではありません。

## 南入口と道路の接続

前回の舗装は側面に高い垂直面が残っていました。入口正面の敷居高4.4mを保持し、左右へ下る面に変更します。両側・南端の高さは旧市街地の実ジオメトリ2,448点に合わせ、道路面の約15mm上へ接続します。建物に近接する南端は狭めます。入口正面の床と屋上設備は維持します。

サンプルの一部では、建物下を避けた旧地面がZ=-2mになっていました。ここは建物沿いの内部点に限定して隣接道路の0.3mを仮の下地高とし、対象点と推定理由を入力JSONに記録しています。外周の接続検査では、この補完を根拠に合格させず、保存された都市の実表面を再確認します。

これは平坦な旧都市モデルへの局所的な接続修正です。西側駐車場全体、実際の擁壁・排水・地下基礎、現地の連続DEMは復元していません。勾配の歩行適合性やバリアフリー性能を認証するものでもありません。

## 検証と再実行

```powershell
# PHASEを build → validate → render-before → render-after の順に別プロセスで実行
& BLENDER --factory-startup --background --threads 2 --disable-autoexec --python-exit-code 1 --python scripts/tower_foundation_v4.py -- --phase PHASE --input PR62_AFTER --output data/local/reviews/tower-foundation-v4-final
python -m unittest discover -s tests
python -m compileall -q scripts tests
```

入力blendのSHA-256、対象4メッシュの指紋、オブジェクト行列を固定します。候補保存後に別プロセスで開き、許可外変更、元の素材・依存画像・表示設定、52m以上の全頂点、元の面接続・属性を照合します。補正した既存鉄骨はBlenderの面三角分割を使って閉鎖性・面向き・各部材の正体積を確認します。舗装は保存された三角面そのものを検査します。

16箇所の鉄骨とプレートの近接、台座による支持、南入口の床高、舗装の外周を最大0.5m間隔で検査します。新しい舗装の各上面三角形の重心でも、既存建物に覆われないことを確認します。高さ0.61m以下の既存舗装・縁石は保護して残し、斜面との重なり箇所数と最大深さを記録します。点検査であり連続的な全衝突の証明ではありません。

比較画像は塔全体、敷地俯瞰、正面、南側、入口、舗装の側面、対向する塔脚の8視点です。同じ世界座標のカメラ・照明・seedで描画します。公開はレビュー用PNGと独自コード・metadataのみで、都市blendや参照PDF原本は含めません。

歴史資料のGLと展望台の案内高には基準の違いがあります。今回の88mは水平寸法だけに採用し、旧モデル全体の高さや地理原点を検証済みとは扱いません。

## 今回の結果

固定入力から生成した候補を別のBlenderプロセスで再度開き、全体検証に成功しました。対象4部品を変更し、対象外3,364部品・元の材質・依存画像・表示設定を保持しています。入力と候補のhashは検証・描画の前後で不変です。

- 基礎中心間隔：88m。16箇所の鉄骨とプレートの距離は最大約2cmで、全プレートを台座が支持しています。
- 舗装外周564点：既存都市との接続差は最大約15.5cm。高い垂直側面を解消していますが、縁石相当の局所段差は残ります。
- 舗装上面4,686三角形の重心：既存建物との重なりなし。保持した既存舗装・縁石が上面に出る24点を記録し、最大は約15.9cmです。
- Portable checks：408件中400成功、任意条件付き8件skip。compileallと差分の空白検査も成功。
- 既存警告36件と検証範囲の制約を保存後レポートへ引き継いでいます。実物精度と画像の採用判断は人間による確認待ちです。
