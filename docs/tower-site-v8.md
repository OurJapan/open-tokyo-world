# 東京タワー南側の地盤と傾斜した台座

PR #66 の保存候補を不変の入力とし、南側の駐車場と入口舗装を同じ高さの関数で接続します。以前の入口舗装だけが盛り上がる形を改め、駐車場、車路、歩道、地面、低い地上設備を一緒に持ち上げます。台座外装は下部鉄骨の軸に沿って傾斜させます。北側階段の手すりは保存 OSM の `handrail=no` と矛盾していたため、表示を撤回します。

## 根拠と推定

- 東京タワー公式の団体案内は、正面入口を1階、駐車場側入口を2階として説明しています。2階南側出入口の案内も駐車場との直結を確認できます。
- 施設掲載写真では駐車場が南側出入口に広く接続し、南側台座の露出が正面側より低くなっています。台座は鉄骨の傾斜に沿い、下端が外側に寄っています。写真からメートル単位の寸法を測定したという主張はしません。
- 南側入口のモデル高さ4.4mと、前版の国土地理院標高差から置いた駐車場高さ3.2mを維持します。前版の相対基準は絶対標高を確定するものではありません。今回取得した周辺81地点の1m DEM値には崖・低地・建物内が混在するため、そのまま全敷地へ補間しません。
- 台座上端 Z=7m と鉄骨の接続は保持します。外装の傾きは既存の下部鉄骨軸から求めます。上端高さ、外装パネル寸法とテーパーは引き続き推定です。南側の見える高さは、持ち上げた地盤との交差で変わります。
- 北側経路 `1245345677` は保存 OSM に `step_count=8`, `handrail=no` と記録されています。8段は維持します。現地の蹴上げ・踏面・踊り場の寸法は確認できず、前版の0.275mの蹴上げと長い踏面は暫定のままです。階段全体の実物精度を解決済みとは扱いません。

## 変更範囲

南側の高さ変更はタワー局所座標 X=-60〜60m、Y=-90〜-12m に限定し、境界では元の高さへ連続的に戻します。建物内への土の入り込みを避け、FootTown外壁の内側は除外します。地域全体の地形や測量済みの造成形状ではありません。

道路・土地利用面は元の水平位置を維持し、範囲内だけ細分化して高さを変更します。傾斜台座の投影範囲に重なる面を除きます。範囲外の元の面と属性、元頂点、既存の材質は保持します。駐車区画や低い設備にも同じ高さ変位を適用します。台座上の鉄骨・接合部・塔上部・展望台は保護対象です。

新しい地盤にかかる既存の車両2台も、4輪位置の路面から求めた姿勢へ剛体変換します。旧配置データの593台中、インデックス99と506だけが対象です。車体・窓・灯具・ナンバー・タイヤ・リムの9材質メッシュ内の頂点範囲を特定し、同じ車両の全パーツへ同じ変換を適用します。他車両は保持します。これは旧シーンの演出的な交通配置の接地修正であり、現地車両の観測記録ではありません。

車両を含む元のコレクションはレンダー非表示です。その保存設定は変えず、車両確認の2視点だけ、既存の車両材質オブジェクトを一時的に表示します。Before/Afterとも同じ診断表示を適用し、通常の10視点とは区別します。診断用の表示変更はblendへ保存しません。

手すりは元オブジェクトとメッシュを残して viewport/render の両方を非表示にします。追加・削除を伴わず、根拠が変わった場合に追跡可能です。

台座の下端は北側の地盤のくぼみより下まで延ばし、傾斜変更で生じる接地の隙間を防ぎます。地中の終端 Z=-2.1m はメッシュを閉じるための処理であり、実際の基礎深さを示しません。

## 再現と検証

`scripts/prepare_tower_site_v8.py` が公開メタデータから地盤計画を生成します（Shapely 2.1.2）。`scripts/tower_site_v8.py` の `build`, `validate`, `render-before`, `render-after` を、それぞれ Blender 4.5.1 LTS の別プロセスで実行します。入力は `tower-site-v8-input.json` の SHA-256 と29対象のメッシュ指紋に固定されています。

保存後に許可外オブジェクト・材質・データ数・メタデータの不変、地盤と台座の閉じた形状、変更範囲外の保持、地面と舗装の関係、南側敷居、北側8段の障害を確認します。技術検証は実寸や通行安全の保証ではありません。

最終候補は前版と同じ10視点と、接地修正した車両の2視点を同条件で描画します。公開対象はオリジナルコード、派生メタデータ、承認範囲のレビューPNGです。都市blend、参照写真、標高APIの取得原本、旧テクスチャは同梱しません。
