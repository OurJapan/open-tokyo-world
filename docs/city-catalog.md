# 既存の街を画像付き一覧で確認する

道路・地面・建物・植栽・車両・設備などを13分類に分け、部品名と既存の出典・許諾記録を確認するローカルカタログです。街の改善対象を選ぶときと、制作元を思い出すときに使います。固定したPR #12採用版を読み込み、元のblendには保存しません。

## 作成と閲覧

[制作環境](contributor-workspace.md)の手順で街を登録してから、リポジトリのルートで実行します。Blender 4.5.1 LTS、通常のPython 3.11以降が必要です。追加のpipパッケージは不要です。`python` はBlender付属Pythonの実行ファイルへ置き換えられます。

```powershell
python scripts/city_catalog.py --blender 'C:\Program Files\Blender Foundation\Blender 4.5\blender.exe' --input data/local/assets/tokyo-city-pr12/city.blend --output data/local/catalogs/my-city
```

対応GPUを使う場合は `--device OPTIX` を追加します。既定はCPUです。CPUへの暗黙の切り替えはしません。出力先は新しいフォルダーを指定します。入力のbytes・SHA-256・Blender版が違う場合と、既存出力を上書きする場合は停止します。元入力は558,751,758 bytes、SHA-256 `98a3932e6dc972d4ae702d264c1e894d77765a9a3a5e57c8a75591eafd42e926` です。

生成された `index.html` をブラウザーで開きます。「対象だけ／街の中」で画像を切り替え、分類と部品名で検索できます。部品名の一覧では、原版での表示状態、既存記録との対応、画像の参照を確認できます。制作元メモは同じブラウザーに保存され、「制作元メモを保存」でJSONとして書き出せます。保存用の内容も画面に表示するため、ブラウザーがダウンロードを許可しない場合はコピーできます。メモは入力と対象部品のhashに紐付き、配布承認や許諾台帳へ自動反映されません。

`data/local/catalogs/` の画像・詳細一覧・ログはローカル確認用です。Gitで共有するものはコード、分類設定、集計などのmetadataです。カタログ作成によって旧シーンや画像の再配布条件が変わることはありません。

制作コードと固定入力の回収・照合結果は下記の追記に記録しています。原資料との対応と部品単位の許諾範囲を整理し、[配布準備の残作業](city-distribution-plan.md)を満たすまでは街全体の配布完了とは扱いません。

### 2026-09-27の制作元メモ

植栽・車両・設備の制作元について、ご本人から「自分とAIだと思うよ」との回答がありました。[制作元メモ](../sources/city-pr12-authorship-notes.json)に、**ご本人とAIによる制作の見込み・制作記録との照合待ち**として記録しました。

質問に含まれた公園等の樹冠、街路樹・植樹帯、低木・下草、車両、街灯、近景設備の6分類・2,676メッシュへ暫定的に対応付けています。分類への対応は今回の質問文から整理したもので、全メッシュの制作元や外部素材の不使用が個別に確認されたという意味ではありません。固定入力と各分類のhashを保存し、後で制作ファイルと照合できるようにしました。道路・地面・建物や既存の許諾済み部品へ対象を広げません。

上の件数表とカタログの機械照合は2026-09-26時点の結果です。今回の回答は補足する自己申告として別に保持し、77件の既存許諾や街全体の配布状態を変更しません。

その後、元プロジェクトの固定版から制作コードが見つかりました。[部品との対応・取得方法](city-production-sources.md)を追加しています。さらに[不足していた25入力を回収](city-input-recovery.md)し、道路・配置12出力の再生成が保存版とバイト単位で一致しました。街路樹と低木の2,647メッシュは基本形状に加えて、位置・回転・拡縮も一致しました。[追加の照合](city-component-verification.md)では残る29メッシュと31材質、2,676メッシュへの材質割当も一致しました。上表のカタログ集計・許諾状態は変更していません。

## 検証と限界

固定入力を別々のBlenderプロセスで棚卸し・描画し、分類の完全性、画像寸法・有限画素・空画像、実行前後の入力hashを検査します。埋め込みスクリプトは実行しません。コード・許諾台帳・出力画像のhashを保存します。入力版・物体の表示判定はframe 1のactive View Layerに限ります。指紋はmodifier・animation・入れ子の全ノードを完全には網羅せず、実物精度や全画角を検査するものではありません。

[集計と実行記録](../sources/city-pr12-catalog-summary.json) / [分類・画角設定](../manifests/city-catalog-v1.json)。通常の回帰テストは `python -m unittest discover -s tests` です。ローカルの一覧作成には固定した街の入力が必要で、CIで旧モデルを取得することはありません。
