[形状の棚卸し結果](../sources/city-pr12-geometry-audit.json)。3,255 mesh objectsのうち428に `source_url` があり、2,827にはありません。記録の欠如は権利の欠如を意味しません。許諾済みの独自部品も含まれ得るため、既存の許諾台帳との対応付けが必要です。collection数は重複所属の可能性があり、足し算で総数を求めません。

形状のURL記録は365種類です。港区275、千代田区65、中央区1に加えて、**渋谷区24**の配信ファイルを指しています。これは記録された参照先の数で、建物数や元形状との一致件数ではありません。画像382枚の照合対象は3区でしたが、形状を含む街の配布条件の確認対象には渋谷区も追加します。

棚卸しの再実行は以下です。`$blender` にBlender 4.5.1の実行ファイルを指定し、出力を新しいローカルファイルにします。埋め込みmetadataは調査対象の主張として扱い、実行命令や権利の証明として扱いません。

```powershell
& $blender --factory-startup --disable-autoexec --background data/local/assets/tokyo-city-pr12/city.blend --python-exit-code 1 --python scripts/audit_city_geometry.py -- data/local/audits/city-geometry-new.json
```

## 道路について復元が必要な情報

[広場の道路面修正記録](mori-plaza-edge-v1.md)では、保存OSMのSHA-256は `f04e8e70ab24a61ca749375d1ef37401feb0fdc840cc506b670ef71454a6a8ab`、wayは `1443867470`、タグは `area=yes / highway=pedestrian / 中央広場` です。旧 `work/tokyo60/build_city.py` は広場の輪郭を道路として扱い、幅9mの道路と全幅11.1mの歩道状面を生成していました。

この局所診断は記録されていますが、元OSMファイル・取得時点・全街区の生成版・各道路面のway対応を、外部参加者が取得して再現できる組にはできていません。現在のOSMを取り直しても過去版と同じとは扱えません。既存の道路を保持して配布する場合は元データと加工経路を復元し、復元できない部分は出典と生成過程を記録した新しい入力から置き換えます。

OSMはODbLで提供され、公開時は出典とライセンスへの案内が必要です。[OSMの著作権表示](https://www.openstreetmap.org/copyright)と[OSMF表示指針](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)を確認しました。元データ・派生データベース・レンダリングされた作品は、配布形態ごとに整理する必要があります。[ODbL本文](https://opendatacommons.org/licenses/odbl/1-0/)の4.3、4.4、4.6を参照し、道路の加工が派生データベースに該当する場合の提供物も決めます。街全体に一括でMITを付ける整理にはしません。

## PLATEAUの条件と公開候補の作り方

[公式サイトポリシー](https://www.mlit.go.jp/plateau/site-policy/)を再確認しました。出典・加工の表示と個別の例外を確認する必要があります。今回、港区と中央区の個別カタログはHTTP 403、千代田区の個別カタログも取得できなかったため、3区すべての個別条件の確認完了とは記録しません。既存の[港区data221の確認記録](../starter/plateau/NOTICE.md)は保持します。

[同梱する出典表示の下書き](../sources/city-distribution-NOTICE.draft.md)に画像の3区と形状記録に現れる渋谷区、OSM、独自部品の案内を集めました。渋谷区の形状と元データの対応・個別条件も未確認です。個別条件と版の対応が揃ってから確定し、配布候補と同梱します。

次に整理する単位は、**元データと生成コードが不足している道路・簡易建物・植栽等**です。対象ごとに元データの取得先・hash、生成コードの版、出力部品、加工内容、許諾記録を対応付けます。その後、採用した材質と対象部品だけで新しい候補版を固定し、NOTICE、ファイル一覧、hash、取得先を付けて、旧フォルダーへアクセスできない環境で開くところまで検証します。

現時点で外部参加者が公開入力から再生成できる入口は、引き続き[森JP周辺の共通環境](contributor-workspace.md)です。街全体の公開配布先は未整備です。
